# 自定义表情包

评论框表情按钮里的内容由本目录自动扫描生成，**加完文件刷新页面即可生效**，不用改代码。

## 1. 最快用法：直接放文件夹

在本目录下新建一个文件夹，把图片丢进去：

```
assets/emoji/
├── Heo/            # 主题自带
├── GIF/            # 主题自带
└── 我的表情/        # 新建的文件夹 = 新的表情分类
    ├── cat.webp
    ├── dog.png
    └── 开心.gif
```

刷新文章页 → 点评论框的「表情」按钮 → 顶部会多出「我的表情」分类。

- 分类名 = 文件夹名
- 表情名 = 文件名（去掉扩展名）
- 支持格式：`webp` `gif` `png` `jpg` `jpeg` `svg` `avif` `bmp`
- 点击后插入 `:(owo=文件名)`，发表评论时由主题渲染成行内表情

> 文件名建议只用英文、数字、下划线或短横线，例如 `cat`、`cute_dog`；
> 中文文件名可以用，但 `:(owo=...)` 里出现中文时部分编辑器处理起来麻烦。

## 2. 想自定义显示名 / 插入方式：加 info.json

在表情包文件夹里放一个 `info.json`（UTF-8，**不要带 BOM**）：

```json
{
  "label": "猫猫",
  "mode": "emoji",
  "order": 2,
  "titles": {
    "cat": "猫猫歪头",
    "dog": "狗狗震惊"
  }
}
```

| 字段 | 说明 |
| --- | --- |
| `label` | 表情按钮里显示的分类名，不填则用文件夹名 |
| `mode` | `emoji`（默认）：点击插入 `:(owo=文件名)`，行内显示；`image`：点击插入 Markdown 图片，适合大图/动图 |
| `order` | 分类排序，数字小的在前；不填为 999，同值按文件夹名排序 |
| `titles` | 文件名 → 中文名，决定鼠标悬停提示，也决定表情在列表里的顺序 |

## 3. 两种插入方式的区别

| mode | 点击后插入 | 显示效果 | 适合 |
| --- | --- | --- | --- |
| `emoji` | `:(owo=cat)` | 行内小表情，字号自适应 | 静态小表情、聊天表情 |
| `image` | `![猫猫歪头](图片地址)` | 正文图片，可点击放大 | 大图、GIF 动图 |

## 4. 注意事项

- **表情 key（文件名）全站唯一**：多个分类里有同名文件时，按分类顺序取第一个。
- 删除某个分类 = 直接删除文件夹；删掉后历史评论里对应的 `:(owo=xxx)` 会原样显示成文字。
- 图片请自行压缩，108 张表情包的总大小建议控制在 1MB 以内，避免评论框首次展开时卡顿。
- 主题升级不会覆盖本目录里你自己加的文件夹。
